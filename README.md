# Sanjeevani — Multilingual Health Triage

## Problem
In rural areas, patients often lack access to primary medical consultations and face language barriers when accessing digital health information. Sanjeevani is a GenAI-powered assistant that interprets symptoms in Hindi/English and classifies them into structured triage categories (Green, Yellow, Red).

## Setup
1. Open the notebook in Google Colab.
2. Run each cell to view patient cases and triage outputs.
3. No API credits required — outputs are pre-generated.

## Example Outputs
- Patient 1: Green (Mild) → Stress/dehydration
- Patient 2: Yellow (Doctor Visit) → Possible infection
- Patient 3: Red (Emergency) → Heart/respiratory warning

## Disclaimer
⚠️ This tool is for triage only, not medical diagnosis. For emergencies, seek professional care.
